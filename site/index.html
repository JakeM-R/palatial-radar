How it works

A GitHub Action runs fetch.py daily at 06:00 UTC and rebuilds this page. Items are sorted by keyword rules, and each row shows the rule that put it there. Rules are blunt: expect some irrelevant items and some misses.

In production, the rules would be replaced by a language model that reads each item, writes a one-line summary, and scores relevance to Palatial’s roadmap and accounts. The feeds, baseline and drafting flow stay the same.

This week’s counts include every item in the feed. The 8-week norm adds up each feed’s own weekly average over the weeks it actually covers, so news feeds that only carry recent posts don’t inflate the comparison. Small counts are never called unusual.
